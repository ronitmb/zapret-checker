# Zapret ALT Checker

Небольшая программа для проверки, **какие пресеты из
[zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) реально работают у вас**
(в т.ч. варианты `general (ALT).bat`, `discord (ALT).bat` и т.д.).

## Сборка (папка `build\`)

После `build.cmd` в папке `build\` появляются:

| Файл | Что это |
|---|---|
| `Setup.exe` | **Мастер установки** (как у обычных программ): приветствие → папка → ярлыки → установка → готово |
| `ZapretChecker.exe` | сама программа |
| `README.txt` | краткая инструкция |

Распространять можно всю папку `build\` целиком: пользователь запускает `Setup.exe`.

Что делает установщик:
- копирует программу в выбранную папку (по умолчанию `C:\Program Files\ZapretChecker`);
- создаёт ярлык в меню «Пуск» в выбранной **категории** (подпапке: «Zapret», «Сеть», «Утилиты»…);
- создаёт ярлык на рабочий стол;
- по галочке — задачу планировщика для запуска **без окна UAC**;
- кладёт в папку программы `run-no-uac.cmd` (запуск без UAC) и `uninstall.cmd` (удаление ярлыков и задачи).

Про ярлыки: установщик создаёт .lnk как обычный новый файл и **не вызывает никаких
обновлений/перестроений рабочего стола** — новые значки встают в свободную ячейку,
а существующие значки остаются на своих местах и не сдвигаются.

Как работает проверка:

1. останавливает текущий zapret (`winws.exe`);
2. запускает следующий выбранный пресет (окно скрыто);
3. ждёт прогрев (по умолчанию 6 сек);
4. запускает **все 10 тестов параллельно** (~8 сек на пресет вместо ~40 при последовательном);
5. записывает результаты в таблицу, считает вердикт и средний пинг;
6. в конце строит рейтинг и предлагает запустить лучший пресет одной кнопкой.

## Что проверяется

| Тест | Проверка | Роль |
|---|---|---|
| Контроль (ya.ru) | работает ли сеть вообще | служебный |
| YT сайт | `www.youtube.com/generate_204` | критичный |
| YT CDN | скорость картинки с `i.ytimg.com`, КБ/с | доп. |
| YT видео | ближайший сервер `*.googlevideo.com` (через `redirector.googlevideo.com/report_mapping`) | критичный |
| DC API | `discord.com/api/v10/gateway` | критичный |
| DC GW | `gateway.discord.gg` | доп. |
| DC CDN | `cdn.discordapp.com` (реальный файл-аватар) | доп. |
| Cloudflare | `www.cloudflare.com/cdn-cgi/trace` | доп. |
| Twitch | `www.twitch.tv` | доп. |
| Steam | `store.steampowered.com` | доп. |

Пинг считается честно — **TTFB** (время до заголовков ответа), без учёта скачивания тела.

## Итог и выбор лучшего

- Вердикт по каждому пресету: критичные тесты (YT сайт, YT видео, DC API) + дополнительные
  → «✔ отлично» / «✔ хорошо» / «⚠ частично» / «✖ не работает».
- Лучший пресет выбирается по: количеству критичных → дополнительных → **минимальному среднему пингу**,
  подсвечивается зелёным и показывается в итоговом окне с кнопкой «Запустить сейчас?».

## Как пользоваться (после установки)

1. Запустите программу с ярлыка — она всегда стартует с правами администратора.
2. Укажите папку zapret-discord-youtube, выберите пресеты, нажмите **«Проверить»**.
3. В конце согласитесь запустить лучший пресет (или выберите свой в таблице).

## Консольный режим

```
ZapretChecker.exe --test
```
— проверяет только состояние сети **без** запуска пресетов (эталон).

## Нюансы

- Голосовой чат Discord использует UDP — его нельзя проверить извне без входа в звонок;
  HTTP-тесты коррелируют с ним, но 100% гарантию даёт только реальный звонок.
- Если не сменён DNS на рекомендованный из инструкции репозитория, результаты будут хуже.
- Антивирус может ругаться на программу (запускает bat-файлы и убивает `winws.exe`) —
  ложное срабатывание, исходник открыт: `Program.cs`.

## Сборка из исходника

```
build.cmd
```
(использует csc.exe из .NET Framework 4.x, который уже есть в Windows — ничего ставить не нужно).
