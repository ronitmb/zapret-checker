Zapret ALT Checker
==================

УСТАНОВКА
1. Запустите Setup.exe (понадобятся права администратора — это нормально).
2. Мастер: приветствие → папка установки → ярлыки/компоненты → установка → готово.
3. Галочки: ярлык на рабочий стол, ярлык в меню «Пуск» (с выбором категории),
   задача для запуска БЕЗ окна UAC.

ПОСЛЕ УСТАНОВКИ (в папке программы):
- run-no-uac.cmd  — запуск без окна UAC (если выбрали задачу в установщике)
- uninstall.cmd   — удаление ярлыков и задачи (папку удалите вручную)

Ярлыки создаются как новые файлы: существующие значки на рабочем столе
остаются на своих местах и не сдвигаются.
